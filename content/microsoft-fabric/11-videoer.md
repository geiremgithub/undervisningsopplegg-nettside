# Videoer: Microsoft Fabric

Videoene er sortert etter temaene i emnet. Alle er på engelsk og gratis på YouTube. Kanalen **Guy in a Cube** har korte og presise videoer, og **Learn Microsoft Fabric with Will** har lengre gjennomganger.

> Lenkene er kontrollert, og alle videoene var offentlig tilgjengelige i november 2026. Beskrivelsene bygger på tittel, kanal og lengde. Fabric endres ofte, så menyer i eldre videoer kan se litt annerledes ut.
