# Om kursportalen

Kursportalen samler undervisningsopplegg innen data, analyse og AI. Hvert emne består av flere temaer med forklaringer, ferdige eksempler, øvingsoppgaver og fasit, og noen emner har et gjennomgående case som bygges opp fra start til slutt.

## Emnene

- **Datavarehus og dataintegrasjon:** Et seks ukers opplegg i datavarehus, dimensjonsmodellering, ETL/ELT, analytisk SQL, indeksering og spørringsoptimalisering. Caset Nordhandel AS bygges fra kildesystem til ferdig datavarehus med rapporter, og SQL-skriptene kan lastes ned.
- **SAP Analytics Cloud og SAP BTP:** Rapporter, planlegging og prognoser i SAP Analytics Cloud, og plattformen bak: SAP BTP, HANA Cloud og Datasphere.
- **Microsoft Fabric:** Bygg en dataplattform fra rådata til ferdig rapport med lakehouse, notebooks, pipelines, Power BI og sanntidsdata.
- **AI-agenter og skills i GitHub Copilot:** Lag egne agenter og skills som gjør Copilot til en spesialist, steg for steg. Emnet bruker ferdige agenter som jobber med denne kursportalen, blant annet en kursforfatter, en innholdsgjennomgåer og en SQL-veileder.
- **MCP-server (Model Context Protocol):** Hvordan KI-assistenter kobles til verktøy og data med MCP, og hvordan du bygger din egen MCP-server.
- **RAG-løsninger (Retrieval-Augmented Generation):** Hele kjeden fra dokument til svar, med chunking, tokenisering, embeddings, vektordatabase og språkmodell. Du bygger en RAG over kursportalens eget innhold.
- **Microsoft Foundry (tidligere Azure AI Foundry):** Microsofts plattform for KI-utvikling, med modeller, deployment, RAG og agenter, evaluering og sikkerhet.
- **GitHub og versjonskontroll:** Hva Git og GitHub er, de viktigste kommandoene, samarbeid med branches, pull requests og code review, løsning av merge-konflikter, og hvordan du gjør det samme i VS Code.

## Slik bruker du portalen

1. **Velg et emne** under, og start på det temaet du vil. Du trenger ikke følge rekkefølgen.
2. **Les temaet** og gjør oppgavene. Fasit og lærerstoff ligger bak knapper du kan klikke på når du er klar. Hvert emne har også et tema med **utvalgte videoer** (▶) til slutt.
3. **Klikk «Marker som fullført»** når du er ferdig med et tema. Du kan angre.
4. **Følg med på fremdriften** i baren øverst, på emnekortene og med hakemerker i menyen.

Fremdriften lagres bare i denne nettleseren, under navnet ditt. Ingenting sendes noe sted. Bytter du maskin, kan du eksportere fremdriften til en fil nederst på siden og importere den der.
