# Videoer: SAP Analytics Cloud og SAP BTP

Videoene er sortert etter temaene i emnet. Alle er på engelsk og gratis på YouTube. Mange er fra SAPs egne kanaler, **SAP Help and Learning** og **SAP Developers**.

> Lenkene er kontrollert, og alle videoene var offentlig tilgjengelige i november 2026. Beskrivelsene bygger på tittel, kanal og lengde. SAP endrer grensesnittet ofte, så noen skjermbilder i videoene kan avvike litt fra det du ser.
