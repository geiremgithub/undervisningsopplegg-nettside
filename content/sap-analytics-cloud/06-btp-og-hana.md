### 13.1 Første steg i BTP Cockpit

1. Logg inn på **BTP Cockpit** (lenken får du fra BTP Trial eller fra organisasjonen).
2. Åpne **subaccounten** din.
3. **Entitlements:** sjekk at tjenestene du trenger er tildelt, for eksempel *SAP HANA Cloud* og *SAP Business Application Studio*.
4. **Service Marketplace:** her finner du alle tilgjengelige tjenester.
5. **Instances and Subscriptions:** viser hva som er opprettet.
6. **Security → Users / Role Collections:** her styrer du tilganger.

### 13.2 Tre måter å bruke en tjeneste på

| Type | Hva det betyr | Eksempel |
|---|---|---|
| **Subscription** | Ferdig SaaS-applikasjon du abonnerer på | SAP Business Application Studio, SAP Build Apps |
| **Service instance** | En instans av en tjeneste du bruker fra egen app | SAP HANA Cloud, XSUAA |
| **Runtime** | Kjøremiljø for egen kode | Cloud Foundry, Kyma (Kubernetes) |

## 14. Eksempel 9: SAP HANA Cloud med SQL

### 14.1 Opprett en HANA Cloud-instans

1. Abonner på **SAP HANA Cloud** i subaccounten via *Service Marketplace*.
2. Åpne **SAP HANA Cloud Central** → **Create Instance** → **SAP HANA Database**.
3. Velg et navn, for eksempel `nordlys-hana`, og et passord for `DBADMIN`.
4. Under **Connections**, velg **Allow all IP addresses** for testing (aldri i produksjon).
5. Åpne **SAP HANA Database Explorer** når instansen kjører.

> ⚠️ HANA-instanser i prøve- eller gratisversjonen stoppes automatisk hver natt. Start den igjen fra HANA Cloud Central.

### 14.2 Opprett skjema og tabeller

```sql
CREATE SCHEMA NORDLYS;
SET SCHEMA NORDLYS;

CREATE COLUMN TABLE PRODUKT (
    PRODUKT_ID   INTEGER PRIMARY KEY,
    PRODUKTNAVN  NVARCHAR(100),
    KATEGORI     NVARCHAR(50),
    PRIS         DECIMAL(10,2)
);

CREATE COLUMN TABLE SALG (
    SALG_ID      INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    DATO         DATE,
    REGION       NVARCHAR(20),
    BY_NAVN      NVARCHAR(50),
    PRODUKT_ID   INTEGER,
    ANTALL       INTEGER,
    OMSETNING    DECIMAL(15,2),
    KOSTNAD      DECIMAL(15,2)
);
```

> 💡 `COLUMN TABLE` lagrer data kolonnevis i minnet. Det gjør aggregeringer som `SUM` over millioner av rader svært raske. Dette er HANAs viktigste styrke.

### 14.4 Spørringer

```sql
-- Omsetning og dekningsbidrag per kategori
SELECT p.KATEGORI,
       SUM(s.OMSETNING)                AS OMSETNING,
       SUM(s.OMSETNING - s.KOSTNAD)    AS DEKNINGSBIDRAG,
       ROUND(SUM(s.OMSETNING - s.KOSTNAD) / SUM(s.OMSETNING) * 100, 1) AS DB_PROSENT
FROM SALG s
JOIN PRODUKT p ON s.PRODUKT_ID = p.PRODUKT_ID
GROUP BY p.KATEGORI
ORDER BY OMSETNING DESC;
```

```sql
-- Rangering av byer innen hver region (vindusfunksjon)
SELECT REGION, BY_NAVN, SUM(OMSETNING) AS OMSETNING,
       RANK() OVER (PARTITION BY REGION ORDER BY SUM(OMSETNING) DESC) AS RANGERING
FROM SALG
GROUP BY REGION, BY_NAVN;
```

```sql
-- Månedlig akkumulert omsetning
SELECT TO_VARCHAR(DATO, 'YYYY-MM') AS MAANED,
       SUM(OMSETNING) AS OMSETNING,
       SUM(SUM(OMSETNING)) OVER (ORDER BY TO_VARCHAR(DATO, 'YYYY-MM')) AS AKKUMULERT
FROM SALG
GROUP BY TO_VARCHAR(DATO, 'YYYY-MM')
ORDER BY MAANED;
```

### 14.5 View og prosedyre

```sql
CREATE VIEW V_SALG_PER_KATEGORI AS
SELECT p.KATEGORI, s.REGION, SUM(s.OMSETNING) AS OMSETNING
FROM SALG s JOIN PRODUKT p ON s.PRODUKT_ID = p.PRODUKT_ID
GROUP BY p.KATEGORI, s.REGION;

CREATE PROCEDURE P_OPPDATER_PRIS (IN i_kategori NVARCHAR(50), IN i_faktor DECIMAL(5,2))
LANGUAGE SQLSCRIPT AS
BEGIN
    UPDATE PRODUKT SET PRIS = PRIS * :i_faktor WHERE KATEGORI = :i_kategori;
END;

CALL P_OPPDATER_PRIS('Sykkel', 1.10);
```
